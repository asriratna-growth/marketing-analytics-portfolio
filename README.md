# Featured Project

## Marketing Funnel Performance Analysis | Toy Store E-Commerce

### Project Overview

This project analyzes an e-commerce marketing funnel using website session, pageview, and order data.

The objective is to evaluate:

- Traffic acquisition performance
- Conversion efficiency
- Device behavior
- Funnel progression
- Customer drop-off points

and identify opportunities for revenue growth and user experience optimization.

---

### Tools Used

- SQL
- Google BigQuery
- Looker Studio
- GitHub

---

### Key Findings

- gsearch generated 66.8% of total website traffic.
- Direct / Unknown traffic achieved the highest conversion rate (7.34%).
- Desktop users converted at 8.50%, significantly outperforming mobile users (3.09%).
- The largest funnel drop-off occurred between Products and Cart (63.65%).
- Only 12.37% of product page visitors completed a purchase.

---

### Business Recommendations

1. Improve product page content and CTAs.
2. Optimize mobile shopping experience.
3. Conduct A/B testing on product pages.
4. Review search campaign quality and landing page relevance.
5. Analyze high-converting direct traffic behavior.
